Command line overview

Generated from asm 0.8.0. Every command is also available as asm <command> --help.

Run asm with no command on a terminal to open the terminal UI; piped, it prints the session table.

Options every command accepts

Section titled “Options every command accepts”
OptionMeaning
--jsonEmit machine-readable JSON instead of tables
--agent <AGENT>Restrict to one agent: claude-code, opencode, jcode, codex or antigravity
--project <PROJECT>Restrict to sessions of this project directory
--include-childrenInclude subagent/child sessions (hidden by default)

These narrow what a command acts on. --agent and --project filter the sessions; --include-children adds subagent sessions, which are hidden by default. On push and pull, --all means everything the filters match.

Commands

Section titled “Commands”
CommandWhat it does
asm listList sessions across all agents (default command)
asm projectsList projects with session counts.
asm showShow one session’s metadata.
asm resumeResume a session interactively in its native agent
asm renameSet a session’s title (uses the agent’s native mechanism)
asm moveMove a session to another project directory / worktree
asm archiveArchive a session (OpenCode: native flag; Claude: moved into asm’s archive store)
asm unarchiveRestore an archived session
asm deleteDelete a session and all its sidecars (backed up first)
asm sendSend a message into an existing session and stream the reply
asm importImport a session into another agent (the flagship)
asm exportExport a session as Session IR (versioned JSON)
asm worktreesList git worktrees of a repo and the sessions living in each
asm searchFull-text search across every session’s conversation
asm indexRebuild the search index and report on it
asm doctorCheck agent stores for problems (duplicate ids, stale locks, …)
asm syncVersion the archive store with git (transport stays yours)
asm updateReplace this binary with the latest release
asm hubRun or manage a hub that machines sync sessions through
asm joinJoin this machine to a hub, with the token asm hub serve printed.
asm pushUpload sessions to the hub.
asm daemonKeep pushing this machine’s sessions to the hub, each once it has been still for an interval.
asm pullBring a session from the hub onto this machine
asm remoteSee what is on the hub, beside what is here
asm tuiOpen the interactive TUI browser
asm serveServe the web UI (loopback by default)
